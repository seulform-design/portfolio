Overview & Challenge

독특한 레이아웃과 인터랙션을 실험한 개인 포트폴리오 컨셉 사이트입니다. CSS Grid와 Flexbox를 복합적으로 사용하여 비정형적인 레이아웃을 구현하고, 스크롤 기반 애니메이션을 적용하여 시각적 재미를 더했습니다.

이 프로젝트는 "정형화된 그리드에서 어떻게 벗어날 수 있는가?"에 대한 기술적 답변이며, 동시에 사용자에게 지루하지 않은 브라우징 경험을 제공하는 것을 목표로 했습니다.

Technical Execution

프레임워크 없이도 '조형적인 웹'이 가능한지 확인하기 위해 세 가지 축을 실험했습니다.

  • Asymmetric Grid12컬럼 그리드의 한계를 넘어선 비대칭 레이아웃 설계.
  • Scroll InteractionIntersection Observer로 고성능 스크롤 애니메이션 구축.
  • Modular CSS재사용 가능한 컴포넌트 단위의 CSS 아키텍처 실험.
